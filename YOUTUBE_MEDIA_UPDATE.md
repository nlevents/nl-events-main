# YouTube Shorts & Review Videos — Admin Update

## What was fixed
- Added **YouTube Shorts & Reviews** to the main Admin sidebar under Catalog.
- Added dedicated tabs for **YouTube Shorts** and **Review Videos**.
- Shorts can be added, edited, deleted, hidden/shown, and ordered.
- Review videos can be added, edited, deleted, hidden/shown, and ordered.
- YouTube thumbnails are generated automatically from the video ID when available.
- Optional occasion and location metadata can be stored with each video.
- Public Shorts and Review Video sections only show items marked Live and follow Display Order.
- Existing backup/export support already includes both Shorts and Review Videos.
- Existing real YouTube launch links remain supported; no fake demo videos are added.

## Admin path
`/admin/video-content`

## How to add a Short
1. Open **Admin → YouTube Shorts & Reviews**.
2. Choose **YouTube Shorts**.
3. Paste a URL such as `https://www.youtube.com/shorts/VIDEO_ID`.
4. Add caption, occasion/location if needed.
5. Keep **Show this Short on the website** checked.
6. Click **Add Short**.

## How to add a review video
1. Open **Admin → YouTube Shorts & Reviews**.
2. Choose **Review Videos**.
3. Paste a YouTube watch URL or `youtu.be` URL.
4. Add customer name, caption, occasion/location if needed.
5. Keep **Show this review video on the website** checked.
6. Click **Add Review Video**.
